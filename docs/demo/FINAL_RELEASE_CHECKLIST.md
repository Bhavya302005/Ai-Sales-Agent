# Final release checklist

## Before recording

- [ ] Database is migrated and the demo seed/reset completes.
- [ ] Exactly one synthetic, consented test contact is selected.
- [ ] Company knowledge is approved and the campaign is active.
- [ ] Runtime call pause is off only during the approved call window.
- [ ] Provider cards are described as ready, configured, or unavailable exactly as shown.
- [ ] Browser is at a mobile-friendly zoom and no secret-bearing tabs are visible.

## Recording path (3–5 minutes)

1. Business knowledge and approved offering.
2. Sourced requirement with original URL, evidence, and explicit unknowns.
3. Enrichment score and lead approval.
4. Calling campaign, consent gate, schedule/retry controls.
5. Existing call transcript, qualification, callback, and CRM handoff.
6. Notifications, funnel, subscription/voice usage, and admin security posture.
7. State the live OmniDimension call limitation if its round trip has not been verified.

## Before submission

- [ ] Run backend lint, types, tests and migration round trip.
- [ ] Run frontend lint, types, tests, production build and the critical browser journey.
- [ ] Run the repository secret scan, including generated demo metadata.
- [ ] Review `REQUIREMENT_COVERAGE.md` against spoken claims.
- [ ] Watch the final recording once for exposed contact data, credentials, or unsupported claims.
- [ ] User explicitly authorizes the external form submission.
